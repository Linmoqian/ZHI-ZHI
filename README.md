
# 知枝

英文名 **ZHI·ZHI**，产品标语：

> 让每一个不懂，都长成一条可以回来的分支。

“知”代表知识与认知，“枝”代表可以自由创建、独立探索并重新合并的学习分支。名字简短、友好，也不会让大众用户联想到复杂的 Git 或开发工具。

## 服务对象

核心服务对象是使用 AI 进行自主学习的人，尤其包括：

* 大学生与跨专业学习者
* 需要理解复杂概念的初学者
* 使用 AI 阅读论文、教材和技术文档的人
* 希望长期整理个人知识体系的研究者与知识工作者

产品首先面向大众学习市场，而不是只面向程序员。Git 只是底层机制隐喻，不应成为用户必须理解的概念。

## 最终目的

知枝不是单纯让 AI 回答更多问题，而是解决一个核心矛盾：

> 对话按照时间展开，知识却按照概念关系展开。

它最终要把线性的 AI 聊天转化为一个：

* 可以自由分支的探索空间
* 可以随时返回的学习主线
* 上下文相互隔离的独立思考区域
* 能够总结并合并结论的认知版本系统
* 随学习持续生长的个人知识图谱

最终目标可以概括为：

> 帮助用户在探索复杂知识时不迷路，让每一次提问都沉淀为可回溯、可连接、可继续生长的认知结构。

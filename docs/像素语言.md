可以实现，而且不应把整个网页“低分辨率化”。最适合这款产品的是：

> 现代网页排版 + 像素网格约束 + 体素图标 + 阶梯式分支线。

文字保持清晰，像素感主要由结构、图标、阴影和交互承担。

## 1. 前端渲染分工

| 界面部分   | 实现方式                           |
| ------ | ------------------------------ |
| 左侧分支地图 | React Flow + 自定义节点/连线          |
| 中央对话   | 普通 React DOM                   |
| 右侧节点控制 | React DOM + CSS                |
| 像素方块   | 低分辨率 PNG/WebP Sprite，或整数坐标 SVG |
| 背景网格   | CSS `linear-gradient`          |
| 动画     | CSS `steps()`，避免过度丝滑           |

React Flow 支持自定义节点和边，很适合实现自由拖拽、缩放、分叉和节点选择。[Custom Nodes](https://reactflow.dev/learn/customization/custom-nodes)、[Custom Edges](https://reactflow.dev/learn/customization/custom-edges)

## 2. 建立统一的“像素单位”

推荐以 `4px` 为最小单位：

```css
:root {
  --px: 4px;

  --paper: #f7f4ec;
  --surface: #fffdf8;
  --ink: #24272f;
  --muted: #77776f;
  --line: #d8d3c7;

  --blue: #6f91ff;
  --green: #61c59a;
  --purple: #a985ee;
  --orange: #eea866;

  --border: 2px solid var(--ink);
  --shadow-sm: 2px 2px 0 #d8d1c4;
  --shadow-md: 4px 4px 0 #d8d1c4;
}
```

所有尺寸尽量取 4 的倍数：

```text
间距：4 / 8 / 12 / 16 / 24 / 32
图标：16 / 24 / 32 / 48
按钮高度：40 / 48
卡片圆角：0 / 4 / 8
阴影偏移：2 / 4 / 8
```

这会让不同组件像是由同一种“像素积木”搭出来的。

## 3. 暖白像素网格背景

```css
.app {
  min-height: 100vh;
  color: var(--ink);
  background-color: var(--paper);
  background-image:
    linear-gradient(rgba(70, 64, 54, 0.045) 1px, transparent 1px),
    linear-gradient(90deg, rgba(70, 64, 54, 0.045) 1px, transparent 1px);
  background-size: 24px 24px;
}
```

网格要非常淡，只提供空间感，不能抢走对话内容的注意力。

## 4. 像素卡片

用“切角 + 硬阴影”，不要使用大圆角和模糊阴影：

```css
.pixel-panel {
  position: relative;
  background: var(--surface);
  border: var(--border);
  box-shadow: var(--shadow-md);

  clip-path: polygon(
    4px 0,
    calc(100% - 4px) 0,
    calc(100% - 4px) 4px,
    100% 4px,
    100% calc(100% - 4px),
    calc(100% - 4px) calc(100% - 4px),
    calc(100% - 4px) 100%,
    4px 100%,
    4px calc(100% - 4px),
    0 calc(100% - 4px),
    0 4px,
    4px 4px
  );
}
```

按钮也应像可以按下的积木：

```css
.pixel-button {
  min-height: 40px;
  padding: 8px 12px;

  border: 2px solid var(--ink);
  background: #fff;
  color: var(--ink);
  box-shadow: 4px 4px 0 var(--ink);

  transition:
    transform 80ms steps(2, end),
    box-shadow 80ms steps(2, end);
}

.pixel-button:hover {
  background: #f5f0e6;
}

.pixel-button:active {
  transform: translate(4px, 4px);
  box-shadow: 0 0 0 var(--ink);
}
```

## 5. 体素节点不要用普通 CSS 立方体

普通 CSS `transform/skew` 会产生平滑斜边，不是真正的像素立体感。

更推荐制作一套低分辨率 Sprite：

```text
node-blue-idle.png
node-blue-active.png
node-green-mastered.png
node-purple-merged.png
node-orange-question.png
```

原始资源可以是 `24×24`，页面中放大到 `48×48`：

```css
.pixel-sprite {
  width: 48px;
  height: 48px;
  image-rendering: pixelated;
}
```

```tsx
<img
  className="pixel-sprite"
  src="/sprites/node-blue-active.png"
  alt=""
/>
```

`image-rendering: pixelated` 会在放大低分辨率资源时保留块状边缘。[MDN image-rendering](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/image-rendering)

节点颜色可以形成固定语义：

| 颜色 | 含义      |
| -- | ------- |
| 蓝色 | 当前主线    |
| 紫色 | 概念分支    |
| 绿色 | 已掌握/已完成 |
| 橙色 | 疑问/待解决  |
| 灰色 | 未访问/已归档 |

## 6. 分支线做成“阶梯线”

不要使用普通贝塞尔曲线。使用水平、垂直线段组成的像素路径：

```tsx
function PixelEdge({
  sourceX,
  sourceY,
  targetX,
  targetY,
  selected,
}: {
  sourceX: number;
  sourceY: number;
  targetX: number;
  targetY: number;
  selected?: boolean;
}) {
  const snap = (value: number) => Math.round(value / 4) * 4;

  const sx = snap(sourceX);
  const sy = snap(sourceY);
  const tx = snap(targetX);
  const ty = snap(targetY);
  const middleY = snap(sy + (ty - sy) / 2);

  const path = `M ${sx} ${sy} V ${middleY} H ${tx} V ${ty}`;

  return (
    <path
      d={path}
      fill="none"
      stroke={selected ? "#6f91ff" : "#aba69a"}
      strokeWidth={selected ? 4 : 2}
      strokeLinecap="square"
      strokeLinejoin="miter"
      shapeRendering="crispEdges"
      vectorEffect="non-scaling-stroke"
    />
  );
}
```

`shape-rendering="crispEdges"` 可以提示浏览器优先保持 SVG 边缘清晰。[MDN shape-rendering](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/shape-rendering)

如果希望分支更像“自由生长”，可以保留整体自由布局，但将每条曲线量化为 4px 阶梯，而不是画成完全规则的树。

右侧不承担长文本，宽度控制在 `220–260px` 即可。

## 8. 字体不要全部像素化

面向大众时，正文仍应使用现代无衬线字体。像素字体只用于：

* Logo
* 节点编号
* 小标签
* 空状态标题
* 状态提示

正文、公式和 AI 回答如果也使用像素字体，长时间阅读会很累。

## 9. 最终组件结构

```text
AppShell
├── BranchMap
│   ├── PixelNode
│   ├── PixelEdge
│   └── MapToolbar
├── ConversationPanel
│   ├── MessageCard
│   ├── ConceptAnchor
│   ├── BranchCreateMenu
│   └── Composer
└── NodeInspector
    ├── NodeStatus
    ├── NodeActions
    ├── ContextScope
    └── ParentLink
```

这套风格的关键不是“到处加像素”，而是：

> 文字负责可读性，体素负责节点，阶梯线负责关系，硬阴影负责层级，颜色负责分支语义。

这样既能保留你选中的像素积木气质，又不会变成复古游戏界面。
